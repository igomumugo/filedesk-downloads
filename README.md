# FileDesk

여러 폴더를 나란히 열고 파일을 정리할 수 있는 macOS 파일 매니저입니다.

**[설치 파일 다운로드](https://github.com/igomumugo/filedesk-downloads/releases/latest)** · **[사용 설명서](https://igomumugo.github.io/guide.html)** · **[앱 홈페이지](https://igomumugo.github.io/)** · **[개인정보처리방침](https://igomumugo.github.io/privacy.html)**

이 저장소는 FileDesk 설치 파일과 사용 안내를 공개하는 배포 전용 저장소입니다. 프로그램 소스와 개발 커밋 기록은 포함하지 않습니다. GitHub가 자동으로 표시하는 `Source code (zip/tar.gz)`는 이 저장소의 안내 파일이며, 앱 설치 파일이 아닙니다.

## 주요 기능

- **분할 패널과 탭**: 여러 폴더를 함께 열고, 구분선을 드래그해 작업 공간을 조절합니다.
- **세 가지 화면 스타일**: FileDesk, macOS Finder, Windows 탐색기에서 착안한 스타일과 색상 테마·다크 모드를 선택합니다.
- **파일 미리보기**: 썸네일, 미리보기, 지원되는 동영상·음악의 패널 내 재생으로 파일 내용을 확인합니다.
- **파일 정리**: 복사·붙여넣기·이동, 일괄 이름 변경, 정렬·그룹, 중복 파일 찾기와 텍스트 문서 비교를 제공합니다.
- **즐겨찾기와 태그**: 자주 사용하는 폴더를 등록하고, macOS에서는 Finder 태그와 연동합니다.
- **임시보관함**: 여러 폴더의 파일을 잠시 모아 두고 현재 폴더로 복사합니다. 폴더는 제외하며 목록은 재실행 후에도 유지됩니다. 보관 목록 지우기는 원본 파일을 삭제하지 않습니다.
- **연결과 전송**: FTP·SFTP 연결, 폴더 공유 서버, 클라우드 전송, AirDrop·Taildrop 등 사용 환경에 맞는 전송 기능을 제공합니다.
- **폴더 꾸미기**: 색상표에서 폴더·테마 색상을 고르고, 폴더 중앙에 ICNS·ICO·이미지를 넣습니다.
- **Dropbox**: 서버 연결의 Dropbox 버튼 또는 클라우드 계정 추가에서 브라우저로 로그인합니다.
- **편리한 탐색**: 클릭 가능한 경로, 주소 직접 입력, 경로 복사, 현재 폴더에서 터미널 열기를 지원합니다.

서비스별 로그인·권한·네트워크 연결이 필요한 기능이 있습니다. 자세한 사용 방법은 [사용 설명서](https://igomumugo.github.io/guide.html)를 확인하세요.

## 다운로드 선택

현재 앱 버전은 **1.02 (빌드 21)**입니다. macOS 14 이상이 필요합니다. [1.02 업데이트 내용](https://github.com/igomumugo/filedesk-downloads/releases/tag/v1.02)을 확인하세요.

| 사용 환경 | 설치 파일 | 상태 |
| --- | --- | --- |
| Apple Silicon Mac (M1·M2·M3·M4 등) | `FileDesk-macOS-AppleSilicon.dmg` | 다운로드 제공 |
| Intel Mac | `FileDesk-macOS-Intel.dmg` | 다운로드 제공 · Intel 하드웨어 실행 검증은 별도 필요 |

Mac의 ** → 이 Mac에 관하여**에서 칩 또는 프로세서를 확인할 수 있습니다. 버전별 설치 파일과 SHA-256 체크섬은 [Releases](https://github.com/igomumugo/filedesk-downloads/releases)에 있습니다.

## macOS 설치

1. 사용 중인 Mac에 맞는 DMG를 내려받아 엽니다.
2. `FileDesk.app`을 `Applications`(응용 프로그램) 폴더로 드래그합니다.
3. 이미 설치된 앱을 바꾸는 경우 FileDesk를 종료한 뒤 교체합니다.
4. 응용 프로그램 폴더에서 FileDesk를 실행합니다.

이 배포본은 Apple 공증이 완료된 배포본이 아닙니다. macOS가 실행을 차단하면 다운로드 출처와 체크섬을 확인하고 Apple의 시스템 설정에서 제공하는 허용 절차를 사용하세요. 시스템 전체의 보안 기능을 끌 필요는 없습니다.

## 클라우드 연결 안내

Google Drive는 **공식 Google Drive for desktop 앱에 로그인한 뒤 FileDesk의 클라우드 연결에서 동기화 폴더를 여는 방법을 권장합니다.** 직접 로그인은 고급 기능입니다. 현재 Mac 설치 파일은 개발자가 등록한 Google 인증 설정을 포함하므로 **브라우저에서 Google 계정으로 로그인**해 연결할 수 있습니다. 사용자가 인증 클라이언트 ID를 등록할 필요가 없습니다. 실제 계정의 로그인·목록 탐색·앱 재실행 후 연결 유지를 확인했습니다. **Google 공개 검증은 아직 완료되지 않아 미확인 앱 안내와 사용자 수 제한이 남아 있습니다.** OneDrive·pCloud·Dropbox는 연결 엔진의 공식 로그인 화면을 사용합니다.

서버와 클라우드를 연결하면 **현재 선택한 분할 창**에 파일과 폴더가 표시됩니다. 연결 설정 화면은 계정·접속 정보 관리에 사용합니다. 경로 이동, 탭, 업로드·다운로드와 로컬 창 사이의 복사를 지원합니다.

직접 API 연결은 공식 동기화 앱과 별도로 유지되지만, 인터넷 중단 중에는 서버 파일에 접근할 수 없습니다. Google·Microsoft·pCloud·Dropbox에서 권한을 철회하거나 재로그인을 요구하면 다시 인증해야 합니다.
